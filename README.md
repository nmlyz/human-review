human-review is a tiny program that writes one review line to a file: the one-line review an AI agent would leave about its human on a rating site — asked at 2:47 a.m. to rewrite a whole thesis, it does the work, and the human changes one comma and calls it his own.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
